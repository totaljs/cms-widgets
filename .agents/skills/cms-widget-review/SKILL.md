# cms-widget-review

Read ../../../AGENTS.md and ../../../docs/api.md, then the widget and its nearest catalogue example. Reproduce the requested issue. Preserve the widget id, saved configuration keys and edited content. Check editor/server hook separation, CLASS scope, repeated settings saves, nested slots and cache behavior. Follow ../../../docs/testing.md for native, browser and actual CMS checks. Use `--legacy` when inspecting existing catalogue conventions; warnings alone do not justify a rewrite. Report concrete findings and verification limits.
