# cms-widget-create

Read ../../../AGENTS.md, ../../../docs/format.md and ../../../docs/api.md. Follow ../../../docs/workflow.md. Start from the smallest matching file in ../../../examples/. Check existing widget ids before selecting one. Keep the contract in `<readme>`, preserve user-edited content and match the consuming CMS UI version. Run the static/native checker and browser checks described in ../../../docs/testing.md; verify settings and publication in a disposable CMS when available. Report any unchecked integration behavior. Deliver one new `widgets/<id>.html`; do not modify unrelated catalogue files or publish without authorization.
