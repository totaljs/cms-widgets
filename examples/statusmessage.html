# Status message Configured text shown in the editor and generated by a server hook on publication. Text is set through settings rather than inline editing. - `message` {String}: text, default We are here to help. An empty string displays an empty paragraph; a missing/non-string value uses the default. Requires the CMS Total.js runtime for text encoding; no additional dependencies. The render callback keeps the wrapper and does not cache output. Test two messages, empty/missing values and HTML-like text: it must display as text rather than markup.
